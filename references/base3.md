# Entonces hagamos los 50 problemas

Pero quiero que lo hagamos **de verdad**, no como ejercicio de brainstorming.

Voy a investigar el mercado ecuatoriano actual y construir una base con problemas que tengan evidencia.

### Cada problema tendrá algo así:

| Campo                   | Qué vamos a buscar                                   |
| ----------------------- | ---------------------------------------------------- |
| Sector                  | Comercio, servicios, turismo, salud, educación, etc. |
| Problema                | Qué está ocurriendo                                  |
| Evidencia               | Dónde encontramos la señal                           |
| Quién lo sufre          | Tipo de empresa/persona                              |
| Cómo lo resuelven hoy   | Manual / Excel / software / empleado / nada          |
| Alternativas existentes | Competidores                                         |
| Costo del problema      | Tiempo, dinero, errores, ventas, etc.                |
| Frecuencia              | Ocasional / frecuente / diario                       |
| Urgencia                | Baja / media / alta                                  |
| Solución posible        | Qué podríamos hacer                                  |
| Lo puedes entregar hoy  | Sí / parcialmente / no                               |
| Inversión inicial       | $0 / baja / media                                    |
| Potencial de repetición | Bajo / medio / alto                                  |
| Potencial de producto   | Bajo / medio / alto                                  |

Y hay una columna que para mí va a ser **fundamental**:

### `¿Cómo llegaríamos al primer cliente?`

Porque un problema puede ser gigantesco y no servirnos si no tenemos ninguna vía razonable de acceso.

## Incluso podemos hacer algo más interesante

Asignar a cada problema una especie de **puntaje de viabilidad**, pero no para decir “este es el mejor negocio”.

Sino para medir objetivamente variables como:

**Demanda observada × dolor × capacidad nuestra × velocidad de entrega × inversión requerida × posibilidad de repetición × acceso al cliente.**

Eso nos permite eliminar ideas que suenan bonitas pero son malas oportunidades.

Y conservar las que tienen señales.

# Y aquí aparece tu frase de los datos

Hay una diferencia entre:

> **Información**

y

> **información procesada para tomar una decisión.**

Internet está lleno de información.

Pero si nosotros conseguimos:

**50 problemas**

→ los clasificamos,

→ encontramos patrones,

→ identificamos 5,

→ validamos 3,

→ probamos 2,

→ conseguimos 1 cliente,

entonces la información se convirtió en **capital**.

Necesitamos **un proceso inteligente de reducción de incertidumbre**.
