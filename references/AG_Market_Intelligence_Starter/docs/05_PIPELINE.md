# 05 — Pipeline de investigación

## Etapas

### 1. Discover
Encontrar fuentes relevantes para una hipótesis concreta.

### 2. Acquire
Capturar contenido respetando límites, robots, términos y controles de acceso.

### 3. Normalize
Convertir HTML/documentos a texto estructurado. Mantener metadata y procedencia.

### 4. Deduplicate
Canonicalización + hash de contenido + similitud cuando sea necesario.

### 5. Extract
Extraer señales mediante schemas estrictos.

### 6. Verify
Buscar evidencia adicional y contradicciones.

### 7. Cluster
Agrupar señales relacionadas para formar problemas.

### 8. Score
Aplicar criterios comerciales y de evidencia.

### 9. Report
Generar informes reproducibles con fuentes.

### 10. Experiment
Convertir una hipótesis en una prueba comercial pequeña.

## Regla

No saltar directamente de una página a una oportunidad. La cadena debe ser observable y auditable.
