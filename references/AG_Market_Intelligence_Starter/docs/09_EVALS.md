# 09 — Evals

Construir un golden dataset de 50–100 ejemplos reales o revisados manualmente.

## Métricas

- schema validity
- extraction completeness
- factual support
- precision@k
- recall@k
- duplicate rate
- sector accuracy
- clustering agreement
- confidence calibration
- evidence-backed problem rate
- false opportunity rate
- human acceptance rate

## Regla de calidad

Una respuesta puede ser lingüísticamente excelente y aun así ser incorrecta. La métrica principal es soporte verificable + utilidad comercial.
