# 14 — Esquema de los 50 problemas

## Dimensiones 1–5

- pain
- frequency
- urgency
- ag_fit
- access
- repeatability
- evidence
- investment (como filtro, no como premio)

## Score inicial

```text
score = pain*0.20
      + frequency*0.10
      + urgency*0.10
      + ag_fit*0.20
      + access*0.15
      + repeatability*0.15
      + evidence*0.10
```

## Gates

No priorizar como oportunidad si:

- evidence < 3
- access < 2
- ag_fit < 3

## Ficha comercial

Cada problema debe terminar con:

1. quién sufre
2. qué ocurre
3. cuándo ocurre
4. evidencia
5. solución actual
6. alternativas/competidores
7. cuánto podría costar resolverlo
8. por qué A&G podría resolverlo
9. experimento de bajo costo
10. criterio de éxito
