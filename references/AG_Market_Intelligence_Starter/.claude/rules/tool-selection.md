# Tool selection

Use the least powerful tool that solves the problem:

1. httpx/simple HTTP for simple pages/APIs.
2. Scrapy for structured/high-volume crawling.
3. Crawl4AI for JS-rendered pages and LLM-friendly extraction.
4. MarkItDown for document normalization.
5. Scrapling when adaptive selectors are actually needed.
6. Browser Use only for genuine interactive browser workflows.
7. Crawlee only if Node/TypeScript becomes justified.
8. Firecrawl only after license/operational review.

Do not add dependencies just because they are popular.
