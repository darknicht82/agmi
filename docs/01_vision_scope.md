# 01 — Visión y alcance

## Problema

Amplia capacidad técnica y poca visibilidad sobre qué problema concreto del mercado ecuatoriano merece convertirse en una oferta comercial repetible. El sistema debe reducir incertidumbre **con evidencia**, no con intuición.

## Pregunta central

> **¿Qué problemas empresariales suficientemente frecuentes, costosos y accesibles existen en Ecuador que A&G pueda resolver con poca inversión inicial y que tengan potencial de repetición?**

Y su forma operativa:

> *"¿Qué problema puedo resolver con lo que ya sé hacer y conseguir que alguien me pague antes de construir demasiado?"*

## Estrategia y etapas

**Guía:** sobrevivir → observar → aprender → probar → cobrar → repetir → construir.

| Etapa | Qué se busca | Señal de paso |
| :--- | :--- | :--- |
| **1 — Caja** | Vender algo entregable rápido con capacidades existentes. Cobrar primero. | Primeros pagos por un problema concreto |
| **2 — Repetibilidad** | Observar qué problema se repite. Servicio → procedimiento → módulo → producto. | 3 clientes distintos pagando por prácticamente lo mismo |
| **3 — Producto** | Automatizar, empaquetar, reducir intervención humana, buscar distribución. | Demanda demostrada con pago |

**Cada experimento debe poder fallar sin hundir.** Antifrágil financieramente. Sin publicidad, logo, marca nueva ni infraestructura pagada antes de evidencia.

## Salidas

### Nivel 1 — Evidencia

fuentes · páginas · documentos · publicaciones · ofertas laborales · empresas · productos/competidores · señales de demanda

### Nivel 2 — Problemas

Cada problema contiene: descripción, sector, actor afectado, **evidencia**, frecuencia, urgencia, impacto, solución actual, alternativas, accesibilidad comercial, **`access_path`** (¿cómo llegaríamos al primer cliente?).

### Nivel 3 — Oportunidades

`problema + evidencia + capacidad A&G + acceso + economía + repetibilidad`

### Nivel 4 — Experimentos

Hipótesis, oferta mínima, público, canal, precio experimental, métrica de éxito, **criterio de abandono**.

## Fuera de alcance inicial

- extracción de datos privados
- bypass de autenticación no autorizado
- evasión deliberada de controles de acceso
- scraping agresivo
- compra automática de bases de datos personales
- generación de conclusiones financieras o legales como hechos
- SaaS público, multi-tenant, facturación, app móvil
- publicidad pagada antes de oferta validada
- asumir que un proyecto previo es el producto — el mercado dirá
